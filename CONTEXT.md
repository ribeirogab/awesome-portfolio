# Portfolio

The portfolio presents a fictional creative professional through their experience, projects, articles, skills, and contact invitation.

## Language

**Portfolio Owner**:
The fictional professional represented by the portfolio. The initial Portfolio Owner is John Doe.
_Avoid_: User, account, profile owner

**Section**:
An ordered, self-contained block of the home page. The Portfolio Owner chooses which Sections exist and in what order.
_Avoid_: Block, widget, page area

**Entry**:
A titled item listed inside a Section, such as an experience or an education.
_Avoid_: Item, card, row

**Experience**:
A time-bound professional engagement attributed to the Portfolio Owner.
_Avoid_: Job, position

**Collection**:
A named set of Projects or Articles. A page lists a Collection in full; a Section can feature part of it.
_Avoid_: List, database, feed

**Project**:
A fictional work sample that demonstrates the Portfolio Owner's capabilities. Projects form a Collection in `portfolio.json`; the home page features some of them.
_Avoid_: Product, case study

**Article**:
A dated, long-form text written by the Portfolio Owner, stored as a Markdown file with frontmatter. Articles form a Collection; the newest ones appear on the home page.
_Avoid_: Post, blog entry, story

**Slug**:
The file name of an Article without its extension. It is the last part of the Article's URL.
_Avoid_: Id, permalink, path
